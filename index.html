How it works

From request to reservation

A condensed view of the two original n8n workflows, with the same node names used in the exported files.

01 · INTAKE

WhatsApp Trigger

A customer's message starts the Pharmacy System workflow.

02 · AI

AI Read Request

Gemini interprets text and available image details and extracts the medicine request.

03 · CHECK

Read Catalog & Match Catalog

Google Sheets provides product, availability, strength and price information.

04 · SAVE

Save Reservation Lines

Reservation details and status are recorded in the Reservation sheet.

05 · REVIEW

Ask Pharmacist

Requests needing human review go to Telegram for an approve-or-reject decision.

06 · MONITOR

ErrorDawaa

Errors can raise alerts; schedule triggers run checks every 15 minutes and at 10 PM Cairo time.
